Guía de Uso de la Herramienta

1. Dashboard

Vista principal con resumen de finanzas, gráficos y acceso rápido a historiales.

2. Registro

Añade ingresos y gastos. Usa "Distribuir" para cubrir un monto desde varios bolsillos. Edita y elimina movimientos desde el historial.

3. Cuentas y Bolsillos

Cuentas: dinero real o deudas. Bolsillos: organización para propósitos específicos.

4. Transferencias

Mueve dinero entre cuentas y bolsillos.

5. Tarjetas

Administra deudas: tarjetas, créditos y préstamos. Registra compras a plazos y abonos.

6. Automatización

Crea presupuestos para transferencias quincenales automáticas a tus bolsillos.

7. Sincronización Firebase ☁️

Los datos se guardan automáticamente en la nube cada vez que realizas un cambio. El indicador en la esquina inferior derecha muestra el estado de la conexión. También puedes exportar/importar archivos JSON como respaldo adicional.

8. Exportar / Importar y Deshacer / Rehacer

Exporta tus datos como archivo JSON de respaldo local. Usa Deshacer/Rehacer para navegar entre acciones recientes.
